Integration checklist

  1. Confirm the hackathon-approved Ring API, SDK, or simulator.
  2. Verify supported event types, permissions, and delivery method.
  3. Implement an adapter in ring_adapter.py.
  4. Keep credentials in environment variables, never in frontend code.
